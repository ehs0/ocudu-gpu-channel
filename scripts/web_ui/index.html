수신 노드별 slot deadline 사용량

Deadline은 이번 IQ 블록의 samples ÷ sample rate입니다. 사용 시간은 해당 수신 노드로 들어오는 모든 엣지를 GPU/CPU 채널 백엔드가 한 번에 합성한 process_superposition wall time이며, 대기·throttle·ZMQ 송신 시간은 포함하지 않습니다. 따라서 같은 수신 노드의 링크들은 하나의 측정값으로 묶입니다.

Sionna 채널 전력 추이

링크별 total path power (dB)
Sionna CIR의 모든 ray coefficient 전력을 합산한 원시 채널 gain입니다. Emulator 보정용 gain offset과 송신 전력을 제외하므로 절대 수신전력(dBm)은 아니며, 값이 더 작아질수록 path loss가 커졌음을 뜻합니다.

엣지 링크별 impulse response · tap 상세

가로축은 tap delay, 세로 stem은 strongest tap 대비 gain입니다. 점 색은 phase를 나타냅니다. 아래 표의 값은 Sionna CIR에서 변환되어 실제 profile_swap에 사용된 tap과 동일합니다.
